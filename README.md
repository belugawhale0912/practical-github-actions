# Midnight Lo-Fi Lounge 🎧

<img src="./images/artwork.jpg" width="250">

**Midnight Lo-Fi Lounge** is a personal RSS podcast feed project automated with GitHub Actions. It delivers chill beats, relaxing ambient audio, and lofi music for developers, students, and creators.

## Project Structure
- `feed.yaml` - YAML source metadata for all podcast episodes.
- `audio/` - MP3 audio track files.
- `images/artwork.jpg` - Custom Lo-Fi album cover art.
- `.github/workflows/` - GitHub Actions workflow for generating XML podcast feed.
